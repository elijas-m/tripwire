# Пилот разметки, ноябрь 2026

20 слепых кандидатов: 2 алерта, 9 near-miss, 9 случайных негативов. Баллы,
уровни и время решения лежат в `sealed.jsonl`; не открывайте его до фиксации
меток.

Пилот размечен по схеме **v1**. Расхождения пилота зафиксировали правила v2:
субъект на уровне эпизода, граница `non_material`/`out_of_scope`, tier 2 для
кинетики и временные метки открытых окон. M2 использует v2; см. `../schema.md`.

## Что делать

1. Откройте `candidates.jsonl`. Для каждого кандидата уже есть строка в
   `labels.template.jsonl`.
2. Заполните поля по схеме `../schema.md` и сохраните как `labels.jsonl`
   (одна JSON-строка на кандидата, без пустых строк).
3. Ключевое поле — `case_type`:
   - `anticipatory` — материальная эскалация произошла после `first_seen` и не
     позже чем через 72 часа;
   - `detection` — событие уже произошло до или в момент `first_seen`, нового
     материального события после него нет;
   - `non_material` — риторика, политика, бюджет, заявления;
   - `out_of_scope` — бытовое событие, культура или театр не соответствует
     субъекту;
   - `unresolved` — 72 часа ещё не прошли.
4. Для `anticipatory` заполните `outcome: 1`, `outcome_type`,
   `outcome_severity` (2 — развёртывание/приказ, 3 — кинетика, 4 —
   стратегическое), `outcome_at` и `evidence`.
5. Для остальных типов: `outcome: null`, `outcome_severity: 0`,
   `outcome_type: "none"`; в `notes` одной фразой объясните тип.
6. `observed_until` — до какого времени вы проверили отсутствие исхода.
   Для негатива по 72-часовому горизонту он должен быть не раньше
   `first_seen + 72h`.
7. Если субъект и театр расходятся, поставьте `in_scope: false` и объясните в
   `notes`.

## Правила

- Исход должен быть строго после `first_seen`. Событие, о котором уже
  сообщается в кандидате, исходом прогноза не является.
- Субъект исхода должен совпадать с субъектом кластера. Чужая эскалация в том
  же театре не считается.
- Доказательства — публичные первичные или tier 0/1 ссылки; собственные алерты
  Tripwire доказательством не являются.
- Сомнительные случаи — `confidence: "low"`; они не пойдут в калибровку.
- Метки не перезаписываются: исправление — новая строка с `supersedes`.

## Независимая разметка

Метки агента лежат в `labels.agent.jsonl` и записываются до просмотра
пользовательских меток. Не открывайте этот файл, пока не закончите свои 20
строк; после этого считается Cohen's kappa по `case_type`.

Пилот не годится для Brier: его кластеры появились до внедрения фиксации
якорного балла, поэтому `score_initial` у них пуст. Калибровка запускается на
M2, где якорный балл уже записывается.
